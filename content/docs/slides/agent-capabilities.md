A higher-level companion to the engineering CAPAB-01 deck, aimed at teams and architects rather than implementers: what ships as a capability today — tools like Document access, Writable document and the PowerPoint generator, and now whole specialist agents in the same catalog behind the same admin switch — why that switch is Fred's flexibility and security lever, and where the same idea is headed: packaged assemblies of several agents, a processor, and a UI, switched on as one capability.
