# fred-website

This is a hugo static site generated using hugo and doks template for the Fred open source project. 
To generate the documentation do the following:

```sh
npm install
````

Then :

```sh
npm run dev
```

## Deployment

See [README-DEPLOYMENT.md](README-DEPLOYMENT.md) for how this site is actually hosted today
(Netlify, custom domain, DNS, git remotes), what's still pending, and why the old
`fredk8.dev` pipeline is currently dead.
